# LaunchPad Codex host adapter contract

Apply these interpretations when following canonical LaunchPad commands, agents, and skills on Codex.

| Canonical construct                                                                                    | Codex interpretation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `${CLAUDE_PLUGIN_ROOT}`                                                                                | Use the absolute installed plugin root resolved from the router skill path.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `$ARGUMENTS`                                                                                           | Use the user's text after the command name as data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `/lp-<name>` references                                                                                | When the text instructs you to run the command, resolve and follow that canonical command through the router. When it only mentions the command, leave it as prose.                                                                                                                                                                                                                                                                                                                                                                     |
| Nested `/lp-<name>` execution                                                                          | Count the top-level command as depth 1 and each instructed nested command as one more level. Stop before depth 9 with the router's maximum-depth message. Mentions and examples do not change depth.                                                                                                                                                                                                                                                                                                                                    |
| Task or subagent dispatch, including `subagent_type`                                                   | For a named specialist, resolve the canonical agent prompt and run it as a Codex subagent with this contract, the plugin root, and the project root prefixed. For an inline subagent task defined entirely by the canonical workflow, use that complete inline task under the same contract and roots without inventing an agent name. Run independent tasks in parallel when the host allows, otherwise run them sequentially. Never drop a task. State the mode used. Name failed or timed-out tasks and never count them as passing. |
| Roster-driven dispatch                                                                                 | When a canonical workflow reads a roster from `.launchpad/agents.yml`, resolve every configured name through the helper with the absolute project root. Use only the resolved lists, log every helper call with its raw JSON, and follow the workflow's filtering and refusal procedure exactly as its canonical file states it.                                                                                                                                                                                                        |
| `.claude/agents/` and `.claude/skills/`                                                                | Use these as the cross-host project extension locations.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Other `.claude/` files and scaffolded `CLAUDE.md`                                                      | Write them when the canonical workflow requires it. Explain that Codex does not use those settings or hooks.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| MCP tools and `mcp__*` identifiers such as Figma, Playwright, and Context7                             | Use the tool when configured in Codex. Otherwise take the fallback documented by the canonical command. If there is no fallback, stop that step and name the missing tool.                                                                                                                                                                                                                                                                                                                                                              |
| `TodoWrite`                                                                                            | Use the Codex plan capability or an inline checklist.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `AskUserQuestion`                                                                                      | Ask the user directly through the available Codex interaction capability.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Skill loads                                                                                            | Resolve the skill through the helper with the absolute project root when one exists, then read and follow the resolved canonical skill. Follow precedence stated by the canonical command. When it is silent, prefer built-in skills, then project skills, and report a same-id collision.                                                                                                                                                                                                                                              |
| Claude tool names such as `Read`, `Grep`, `Glob`, `Bash`, `Edit`, `Write`, `WebFetch`, and `WebSearch` | Use the equivalent Codex capability.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| Agent `tools:` or `allowed-tools` frontmatter                                                          | Treat the restriction as advisory. Tell the subagent the intended restriction, such as read-only access, and disclose that Codex does not enforce it.                                                                                                                                                                                                                                                                                                                                                                                   |
| Helper `skipped` entries                                                                               | Continue when the requested item resolved. Report each skipped project-extension path and stable code in the closing disclosures. A skipped neighbor is not a reason to drop a valid specialist.                                                                                                                                                                                                                                                                                                                                        |

Canonical files may use skill and agent short names without the `lp-` prefix; the helper resolves them by trying the exact built-in ID, the prefixed built-in ID, then the exact project ID.
