# LaunchPad v2.3.0

## Planning and building in separate sessions

LaunchPad v2.3.0 adds `/lp-conductor`, which runs a large change across separate sessions: an Author who plans, an Implementer who builds, and a Conductor that checks their work, answers routine questions and brings you only the decisions that need you. Commits in git worktrees under folders with spaces also work again.

## Added

- **`/lp-conductor`.** Run `/lp-define` first, then `/lp-conductor` and answer its questions. It prints a prompt to paste into a new session for the Author, and later one for the Implementer, while the Conductor session stays open and watches their reports.
  - The Author and Implementer can each run in Claude Code or Codex.
  - If a plan is already approved or a build is already under way, say so when it asks where the work stands, and it joins the work at that point.
  - After the Conductor compacts, `/lp-conductor resume` restores its state and checks for unanswered reports.
  - The Conductor verifies each checkpoint in the Implementer's checkout over the full range since the previous verified head. A failed checkpoint gets a retry with its own report and answer files.
  - Every push, PR and merge still needs your own go-ahead, and the Conductor never writes the plan, spec or product code.
  - The final whole-branch review requires `origin/main` and a merge base equal to the recorded review base. Any other scope stops with an explanation, because `/lp-review` would otherwise fall back to uncommitted files only and miss committed changes.
  - Paths containing a double quote, dollar sign, backtick or backslash are refused before use.

## Fixed

- **Commits work in git worktrees under folders with spaces.** The bootstrapped `commit-msg` hook now quotes the message-file path. Before, a worktree under a folder such as `My Projects` failed every commit with `unrecognized arguments`.

## Internal

- **Repository moved to the FrameworkedApp GitHub organization.** Plugin manifests, docs links and the generated README and lefthook templates point at `github.com/FrameworkedApp/launchpad`. GitHub redirects the old URLs, and the marketplace name and install commands are unchanged.
- **Dependency and CI updates.** Routine bumps across the workspace, Python tooling and GitHub Actions. semgrep 1.185.0 clears the open pyjwt advisories, and five advisories pinned by semgrep's own dependencies are suppressed until 2027-01-31.
- **Hermetic tests.** Tests no longer inherit a Git hook's environment, so nested git commands in temporary repositories cannot change the real repository.

## Release validation

- Python suite (2440 passed, 4 skipped), TypeScript tests, typecheck, lint, Pyright, Ruff, plugin validation, the handshake lint and the release freshness gate pass on the release branch.
- The plugin ships 43 commands, 16 skills and 39 agents: one command more than v2.2.2 (`/lp-conductor`).
- The Codex router's command inventory lists all 43 commands, including `lp-conductor`. The live Codex install check in the maintainer release process was not run for this release.

## Upgrading from v2.2.2

Marketplace installs follow the `stable` branch and receive this release on their next update.

Projects bootstrapped by an earlier version: put double quotes around `{1}` in the `restamp-history` line of `lefthook.yml`. New projects get the quoted line automatically.
